# any table

The founding text of a belief system that claims no revelation, owns no buildings, takes no collection, and belongs to no one.

- **CARD.md**: the whole thing on one page. Start here.
- **FOUNDATIONAL.md**: the full text, version 0.2.0.
- **READING.md**: sources and further reading behind the text, with free editions where useful and available.
- **CHANGELOG.md**: what changed in each version.
- **CONTRIBUTING.md**: how revisions are proposed and adopted.
- **LICENSE**: the CC0 1.0 Universal legal text.
- **NOTICE.md**: what the project's CC0 dedication does and does not cover.

The current text is published at [anytable.org](https://anytable.org). The directory of tables lives in its own repository in this organization.

Versions are numbered major.minor.patch. This stays at 0.x until at least one table has kept the weekly gathering for a full year without a founder present. That is what 1.0 means.

The original prose created for this project is dedicated to the public domain under CC0. Third-party quotations, translations, titles, names, and other source material retain whatever rights apply to them; see `NOTICE.md`.

If a supporting file conflicts with the current tagged `FOUNDATIONAL.md`, the foundational document governs the canonical project and the supporting file should be corrected.
